# Code Challenge 2: Enhance the AI Workspace Interface

---

## Challenge Overview

Now that you have completed the **AI Workspace** dashboard, your next task
is to improve its visual appearance using **Tailwind CSS**.

Your objective is to make the application look more modern and visually
appealing **without changing any functionality**. Focus only on improving
the design of the existing components.

You **must not** add JavaScript or TypeScript code. This challenge is
entirely focused on applying Tailwind CSS utility classes.

---

## Components to Improve

Enhance the following components:

- `Welcome.vue`
- `Statistics.vue`
- `Footer.vue`

---

## Requirements

### 1. Welcome Component

Improve the welcome section by adding a more attractive layout.

Requirements:

- Add a background color or gradient
- Increase spacing around the content
- Improve the typography
- Highlight the dashboard title
- Add one action button (for example, **Explore AI Tools**)
- Make the layout responsive

---

### 2. Statistics Component

Improve the statistics section.

Requirements:

- Add a section background
- Increase spacing between cards
- Improve the section title
- Center the statistics cards
- Add hover effects to each card
- Add smooth transitions
- Improve the visual hierarchy

---

### 3. Footer Component

Create a more professional footer.

Requirements:

- Add navigation links
- Include copyright information
- Add social media links or icons
- Improve spacing
- Add hover effects
- Center the content on mobile devices

---

---

## Rules

- Do **not** modify the JavaScript or TypeScript code.
- Do **not** create new Vue components.
- Do **not** remove any existing content.
- Improve the design **only** by applying Tailwind CSS utility classes.
- Keep the application fully responsive.

---

## Expected Learning Outcomes

By completing this challenge, you will strengthen your understanding of
Tailwind CSS by applying utility classes to improve an existing user
interface. You will practice responsive design, spacing, typography,
colors, hover effects, transitions, Flexbox, and CSS Grid while creating
a cleaner and more professional dashboard without writing any custom CSS.
