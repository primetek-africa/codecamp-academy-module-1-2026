# Code Challenge 1 :  Build the Project Statistics Section

---

## Problem

The **DevTasks** application already allows users to manage their daily
development tasks. However, every task management application also displays
a quick summary of the user's progress.

Your challenge is to create a new **Project Statistics** section that appears
**below the "Today's Tasks" section and above the footer**.

This section **does not require any JavaScript**. All values are static and
should be displayed using HTML and Tailwind CSS utility classes.

---

## Requirements

Create a new section titled **Project Statistics**.

The section must contain **three statistic cards** displayed side by side on
desktop and stacked vertically on mobile devices.

Each card must display:

### Card 1

- Title: **Completed Tasks**
- Value: **12**

### Card 2

- Title: **Pending Tasks**
- Value: **5**

### Card 3

- Title: **Current Sprint**
- Value: **Sprint 4**

---

## Layout Requirements

Use Tailwind CSS to create:

- A white background
- Rounded corners
- Shadow
- Internal padding
- Responsive layout
- Centered text inside each card
- Different text sizes for the titles and values
- A small gap between the cards

---

## Tailwind Concepts to Practice

This challenge should reinforce the following Tailwind utility classes:

- `grid`
- `grid-cols-1`
- `md:grid-cols-3`
- `gap-*`
- `bg-white`
- `rounded-xl`
- `shadow-lg`
- `p-*`
- `text-center`
- `text-*`
- `font-bold`
- `font-semibold`
- `text-gray-*`
- `text-blue-*`
- `mb-*`

## Instructions

- Do **not** write any custom CSS.
- Do **not** modify the existing sections.
- Do **not** use JavaScript.
- Use **only Tailwind CSS utility classes**.
- Make sure the layout is fully responsive.

---

## Learning Objective

By completing this challenge, you will practice creating responsive layouts
using **CSS Grid** and Tailwind CSS utility classes. You will reinforce
concepts such as spacing, typography, colors, shadows, rounded corners, and
responsive breakpoints while building a professional dashboard component
without writing a single line of custom CSS.
