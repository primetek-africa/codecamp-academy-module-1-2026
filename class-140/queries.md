# Code Challenge 2: SQL Query Practice
## Electronics Store Database

### Objective

Practice writing SQL queries to retrieve information from a PostgreSQL
database using the `SELECT` statement and its most common clauses.

The database has already been created and populated with data.

**Do not modify the database.** Use only `SELECT` statements.
