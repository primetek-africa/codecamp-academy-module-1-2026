# Code Challenge 1: Expand the StreamPlus Landing Page

---

# Objective

Congratulations! You have successfully built the first version of the
**StreamPlus** subscription service landing page using **HTML, and Bootstrap.

In this challenge, you will take the role of a **Front-End Developer** who
has received a new feature request from the client.

Your task is to extend the existing application by creating a **new
responsive section** between the **Subscription Plans** section and the
**Footer**.

The objective is to practice Bootstrap components, the Grid System, spacing
utilities, typography, colors, and responsive layouts while following the
same design style used throughout the application.

---

# Scenario

The StreamPlus marketing team wants to highlight why customers should choose
their streaming platform.

They have requested a new **"Why Choose StreamPlus?"** section that presents
the platform's most important features.

This section should encourage visitors to subscribe by explaining the
benefits of the service.

---

# Your Mission

Create a completely new section located **immediately above the footer**.

The section must contain information about the advantages of subscribing to
StreamPlus.

Do **not** modify the existing sections of the project.

Only add the new section before the footer.

---

# Requirements

Your solution must include the following elements.

## 1. Section Container

Create a responsive Bootstrap container.

Example heading:

```text
Why Choose StreamPlus?
```

Include a short paragraph introducing the section.

---

## 2. Bootstrap Grid

Use Bootstrap's Grid System.

The section must contain **three responsive columns**.

Suggested classes:

```html
row
col-md-4
```

Each column should automatically stack on smaller screens.

---

## 3. Feature Cards

Each column must contain one Bootstrap Card.

Every card should include:

* An icon
* A title
* A short description

Example topics:

* Unlimited Movies
* Watch Anywhere
* Cancel Anytime

You may choose different feature names if you prefer.

---

## 4. Bootstrap Icons

Each card must display a Bootstrap Icon.

Choose icons from the Bootstrap Icons library.

Examples:

* Film
* Television
* Cloud Download
* Device SSD
* Globe
* Camera Video
* Collection Play

---

## 5. Bootstrap Button

At the bottom of the section, add a centered button.

Example:

```text
Start Your Free Trial
```

Use one of Bootstrap's button styles.

---

## 6. Responsive Design

Your layout must look correct on:

* Mobile phones
* Tablets
* Desktop computers

The cards should automatically reorganize according to the screen size.

# Design Guidelines

Your new section should follow the same visual style as the rest of the
application.

Consider the following recommendations:

* Maintain consistent spacing.
* Use professional typography.
* Align elements correctly.
* Keep card sizes consistent.
* Select meaningful icons.
* Make the section visually balanced.
* Avoid excessive colors.
* Use Bootstrap utilities instead of writing custom CSS whenever possible.

# Submission Requirements

Before submitting your project, verify the following checklist.

* The new section is located above the footer.
* The layout is fully responsive.
* Three Bootstrap Cards are displayed.
* Each card contains an icon, title, and description.
* Bootstrap spacing utilities are used correctly.
* The section includes a centered call-to-action button.
* The design matches the existing StreamPlus application.
* No existing functionality has been broken.
